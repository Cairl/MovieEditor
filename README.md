# MovieEditor

> 基于 FFmpeg 的终端视频编辑工具 —— 在命令行中对视频进行转码、裁剪、音轨选择、字幕处理等操作

## 功能特性

- **电影/剧集双模式**：单文件为电影模式，文件夹为剧集批量模式
- **视频设置**：
  - H.265 (HEVC) / H.264 编码切换
  - 硬件加速编码器支持：NVENC (NVIDIA)、QSV (Intel)、AMF (AMD)
  - 分辨率缩放：原始 / 75% / 50% / 25%
  - 画面裁剪：可设置上下左右裁剪像素数
  - 时间截取：支持 `HH:MM:SS` 格式设置起止时间
- **音频设置**：
  - 音轨选择：自动探测并列出所有音频流（含语言标签），支持独立开关
  - 编码选项：copy / AAC / MP3 / AC3 / FLAC
  - 可切换重编码/直接复制模式
- **字幕设置**：
  - 三种字幕模式：禁用 / 内挂（保留流）/ 烧录到画面 / 外挂字幕文件
  - 字幕流选择：自动探测内嵌字幕，支持独立开关
  - 外部字幕：支持 .srt / .ass 等格式
  - 字幕编码：mov_text / copy
- **剧集批量处理**：
  - 统筹编辑模式：统一设置，批量处理所有剧集
  - 逐集编辑模式：每集独立设置
  - 剧集切换：左右方向键切换当前编辑剧集
- **FFmpeg 命令预览**：开始处理前可预览完整 FFmpeg 命令行
- **实时进度显示**：带闪烁动画和进度条的编码进度，显示速度/耗时/剩余时间
- **差分文件名**：自动解析文件名差异，在剧集模式中显示简短辨识名
- **日志系统**：自动记录每次处理的完整日志到 `log/` 目录

## 技术栈

- Python 3.x
- **FFmpeg / FFprobe**：视频处理核心引擎
- **ctypes / msvcrt**：Windows 终端底层控制
- **subprocess**：子进程管理与进度流解析
- 无 Python 外部依赖

## 安装

```bash
git clone <repo-url>
cd MovieEditor
```

### 前置要求

- **FFmpeg** 和 **FFprobe**：需安装在 PATH 中
  - Windows 推荐下载：https://ffmpeg.org/download.html
  - 确保 `ffmpeg` 和 `ffprobe` 命令在终端可用

## 使用

### 基本用法

```bash
# 电影模式：处理单个视频文件
python main.py "D:/Videos/movie.mp4"

# 剧集模式：处理包含多集的文件夹
python main.py "D:/Videos/TVShow/"
```

### 调试模式

```bash
python main_debug.py
```

`main_debug.py` 预置了测试路径，方便开发调试。

### 操作流程

1. **启动**：通过命令行参数传入视频文件或文件夹路径
2. **视频设置**：选择编码格式、分辨率、硬件加速器
3. **音频设置**：选择保留的音轨和编码格式
4. **字幕设置**：选择字幕处理方式（烧录/内挂/外挂/禁用）
5. **预览命令**（可选）：查看完整 FFmpeg 命令
6. **开始处理**：自动执行转码并显示实时进度

### 编码期间按键

| 按键 | 功能 |
|------|------|
| Ctrl+C | 终止当前编码 |

## 配置说明

所有设置均在运行时的 TUI 菜单中进行，无预设配置文件。主要可配置选项：

### 视频参数

| 选项 | 说明 | 可选值 |
|------|------|--------|
| 编码格式 | 视频编码器 | H.265 (libx265) / H.264 (libx264) |
| 硬件加速 | GPU 编码器 | none / nvenc (NVIDIA) / qsv (Intel) / amf (AMD) |
| 分辨率 | 输出分辨率 | 原始 / 75% / 50% / 25% |
| 裁剪 | 像素裁剪 | 上下左右各 0~N 像素 |
| 时间截取 | 起止时间 | HH:MM:SS 格式 |

### 音频参数

| 选项 | 说明 | 可选值 |
|------|------|--------|
| 重编码 | 是否重新编码 | 开启/关闭 |
| 编码格式 | 音频编码器 | copy / aac / mp3 / ac3 / flac |
| 音轨选择 | 保留的音轨 | 多选开关 |

### 字幕参数

| 选项 | 说明 | 可选值 |
|------|------|--------|
| 模式 | 字幕处理方式 | 禁用 / 内挂 / 烧录 / 外挂 |
| 编码 | 字幕编码器 | copy / mov_text |
| 字幕选择 | 保留的字幕流 | 多选开关 |

## 输出说明

- **电影模式**：输出文件命名为 `{原文件名} (MovieEditor+{时间戳}).mp4`，放在原文件同目录
- **剧集模式**：输出文件放在 `{剧集文件夹名} (MovieEditor+{时间戳})/` 目录中，文件名保持原名
