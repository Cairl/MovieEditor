**Step 1: Add escape helper to `core/helpers.py`**

```python
def escape_ffmpeg_path(path: str) -> str:
    """Escape a file path for use in FFmpeg filter expressions.

    FFmpeg's subtitles= filter requires:
    - backslash → double backslash
    - colon → escaped colon
    - single quote → escaped single quote
    - [ ] → escaped brackets
    """
    return path.replace('\\', '\\\\').replace(':', '\\\\:').replace("'", "\\\\'").replace('[', '\\\\[').replace(']', '\\\\]')
```

### Task 5: Fix subtitle codec "copy" forces mov_text (B-7)

**Objective:** When user selects "copy" for subtitle codec, actually use `-c:s copy` instead of forcing `mov_text`.

**Files:**
- Modify: `ui/app.py:142-143`

**Step 1: Fix the codec logic**

Current code:
```python
cmd.extend(['-c:s', 'mov_text' if settings['subtitle']['codec'] == 'copy' else settings['subtitle']['codec']])
```

The original intent was: MP4 containers need `mov_text`, so when codec is "copy", force `mov_text`. But the user-facing option says "copy" which means "don't re-encode". Let FFmpeg handle the incompatibility naturally.

Change to:
```python
cmd.extend(['-c:s', settings['subtitle']['codec']])

If the user chose "copy" and the format is incompatible with the container, FFmpeg will error with a clear message. This is more honest than silently re-encoding.

### Task 20: Fix shimmer CJK display width (R-14)

**Objective:** Use `get_display_width` instead of `len` for shimmer wave calculation.

```
To:
```python

```

Also need to track character positions by display width. This requires iterating with cumulative display width:
```python
    out = []
    wave_width = 12
    total_w = get_display_width(text)
    center = (offset * (total_w + wave_width * 2)) - wave_width
    pos = 0
    for char in text:
        cw = get_display_width(char)
        dist = abs(pos + cw // 2 - center)
        if dist < 2:
            color = C_BRIGHT
        elif dist < 5:
            color = C_MID
        else:
            color = C_DIM
        out.append(f'{color}{char}')
        pos += cw
    out.append(C_RESET)
    return ''.join(out)
```
