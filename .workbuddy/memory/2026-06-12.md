# 2026-06-12 Code Review Session

## Changes Made

### Critical Bug Fixes
1. **Batch processing stale stream info** (`ui/app.py:349-351`): 
   - Each file in the batch loop now probes its own audio/subtitle streams via `get_audio_streams(path)` and `get_subtitle_streams(path)` instead of relying on stale closure variables from the last `update_current_episode()` call.
   
2. **External subtitle burn-in path** (`ui/app.py:129-130`, `core/helpers.py:115-122`):
   - Added `escape_ffmpeg_filter_path()` helper for FFmpeg filter argument escaping
   - Burn-in now uses full absolute path (`os.path.abspath(sub_path)`) instead of `os.path.basename()`
   - Also respects the `external_subtitle` parameter when provided (per-episode case)

3. **Burn-in logic when no internal subtitle streams** (`ui/app.py:123`):
   - Changed condition from `subtitle_streams` to `(subtitle_streams or selected_external_sub)` to handle case where video has no internal subs but external subs are selected for burn-in

### Reliability Improvements
4. **ffprobe timeouts** (`core/ffmpeg.py`):
   - Added `_FFPROBE_TIMEOUT = 30` seconds constant
   - All `subprocess.run()` calls for ffprobe now include `timeout=_FFPROBE_TIMEOUT`
   - All except clauses updated to catch `subprocess.TimeoutExpired`

5. **FFmpeg end/error logging** (`core/ffmpeg.py`):
   - `log_ffmpeg_end()` now called on: success, failure (non-zero returncode), and shutdown
   - Moved `start_time` outside try block for consistent elapsed time tracking

6. **Ctrl+C shutdown handling** (`ui/app.py:212-214`, `ui/display.py:392-393`):
   - Main menu loop now checks `_shutdown_requested` and exits gracefully
   - `run_menu_loop` checks `_shutdown_requested` on each iteration
   - Added guard after main loop to prevent entering batch processing after Ctrl+C

### Rendering Fixes
7. **Menu cache invalidation after preview** (`ui/display.py`):
   - Added `reset_menu_cache()` function to force full redraw
   - `render_preview_box` now resets `LAST_MENU_LINES = None`
   - Called after per-episode FFmpeg, settings menus, and preview return to main menu

### Code Quality
8. **Duplicate import merged** (`ui/app.py`):
   - Merged two `core.helpers` imports into one statement
